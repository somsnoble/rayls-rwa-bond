# TrustFlow RWA - Rayls Permissioned Bond

## 💡 Project Description
TrustFlow bridges the gap between Traditional Finance (TradFi) and DeFi by introducing **Permissioned Corporate Bonds** on the Rayls Blockchain.

Unlike standard ERC-20 tokens, the **RaylsBond ($RBOND)** enforces regulatory compliance at the smart contract level. It utilizes a "Whitelist" mechanism that restricts token transfers to KYC-verified participants only.

## 🛠 Tech Stack
- **Network:** Rayls Devnet (Chain ID: 123123)
- **Framework:** Hardhat + Ethers.js
- **Standard:** ERC-20 + Ownable (OpenZeppelin)

## 📜 Contract Details

- **Token Name:** Rayls Corp Bond

- **Compliance:** Whitelist-gated transfers (KYC/AML check)
